## 🚀 Projetos

### 🗺️ Pipeline ETL — Auditoria de Obras e Recapes SP
`Python • Pandas • GeoPandas • Shapely • Streamlit • PyDeck • RapidFuzz`

Pipeline end-to-end que consolida 3 fontes operacionais (SGZ 156, Convias e recapeamentos) e cruza notificações com recapes via estratégia em cascata: fuzzy match por nome de rua, CEP, índice espacial por grade e fallback por regional.

- Integração com a API WFS pública do GeoSampa para recuperar geometria real dos trechos
- Corte exato do trecho com Shapely (`substring`, `nearest_points`) e reprojeção EPSG:31983 → EPSG:4326
- Dashboard interativo com PyDeck (PathLayer + ScatterplotLayer), KPIs dinâmicos e exportação CSV
- Correção automática de mojibake, normalização de nomes de rua e parser de coordenadas

🔗 [github.com/brielgaa/obras-sp-pipeline](https://github.com/brielgaa/obras-sp-pipeline)

`Python • Selenium • Pandas • YOLOv8 • PyTorch • OpenCV • ReportLab`

Automação completa de fluxo corporativo aplicado em operações da Sabesp: extração de dados, classificação de imagens com visão computacional, geração de relatórios PDF e encerramento automático de protocolos em sistema web.
