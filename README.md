## Selected work

### [Obras SP Pipeline](https://github.com/brielgaa/obras-sp-pipeline)

Geospatial ETL pipeline for auditing road works and resurfacing records in São Paulo.

- Processes **5,022** resurfacing records from multiple operational sources
- Resolves inconsistent street names with lexical and geographic evidence
- Reconstructs routes using São Paulo's official GeoSampa road network
- Includes human review, persistent caching, checkpoints and topology auditing
- Reduced full cached reruns from roughly **22 minutes to under 2 minutes**

`Python` `Pandas` `GeoPandas` `Shapely` `RapidFuzz` `Streamlit` `PyDeck`

### GEOINFRA Automation

End-to-end automation for operational inspection workflows.

- Web automation and data extraction with Selenium
- Image classification with YOLOv8, PyTorch and OpenCV

- Reduced processing time per case by approximately **80%**

`Python` `Selenium` `Pandas` `PyTorch` `OpenCV` `ReportLab`
